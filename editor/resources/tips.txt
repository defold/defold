# Hidden gems

Did you know? You can type simple math expressions like 640 / 2 in numeric property fields.
Did you know? You can press Ctrl/Cmd+D to select the word under the cursor. Pressing again will select the next occurrence, and so on.
Did you know? You can edit files side by side: right-click on editor tab and select Move to Other Tab Pane.
Drag with the middle mouse button to make a rectangular selection in the code editor!
To move an object along its rotated axis, select Local Space from the Edit menu.

# Tips

To avoid unexpected breaking changes in [library dependencies](https://defold.com/manuals/libraries/#library-url), depend on a versioned release instead of a moving branch such as main or master.
You can open the [Web Profiler](https://defold.com/manuals/profiling/#the-web-profiler) from Debug > Open Web Profiler while a desktop or mobile build with profiler support is running.
Did you know? You can [hot reload code and resources](https://defold.com/manuals/hot-reload/) without stopping your game, including on connected devices running a debug build!
