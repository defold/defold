Rich text markup

Use markup in label text to apply nested visual styles and effects, and inspect links and sprites from Lua.

label.set_text("#label", "Score: <color=#69D2E7>1200</color>")

Syntax

Tags and attribute names are case-sensitive. A paired tag applies to the visible UTF-32 text inside it. Sprite objects use self-closing tags.

<color=#69D2E7>colored text</color>
<ul pattern=dashed>underlined text</ul>
<outline size=2 color=#000000>outlined text</outline>
<shadow x=2 y=-2 color=#00000080>shadowed text</shadow>
<sprite src=images/icon.png width=2em/>

Attributes

Attributes may be unquoted when they contain no whitespace, or quoted with single or double quotes. color and size support a shorthand first value as well as the named value form.

<color=#FF8800>Orange</color>
<color value="#FF8800">Orange</color>
<size='120%'>Larger</size>

Nesting

Tags must close in last-in, first-out order. Inner style values override the same property from an outer style. Different properties combine. Span effects remain independently active, so nested gradients multiply colors and nested position effects add their offsets.

<color=#FFCC00>
    Gold <outline size=2 color=#000000>with a black outline</outline>
</color>

Entities

Use &amp;, &apos;, &gt;, &lt;, and &quot; for reserved characters in visible text. Numeric entities are not currently supported.

Tags

Rich-text tags either style an enclosed text span or describe an object that can be inspected from Lua. Style tags use a matching closing tag. The sprite object is self-closing, while a encloses its linked text.

The previews below use native HTML and CSS and require no external assets or libraries. They demonstrate the closest browser equivalent, not Defold's renderer itself. Four-corner glyph gradients use a bilinear SVG texture, and per-glyph animation is represented by wrapping each displayed character in a span.

color

Sets the glyph face color. Colors use #RRGGBB or #RRGGBBAA. The hash prefix is required; 0xFF0000 and FF0000 are invalid. The result multiplies the label or renderer base color.

AttributeRequiredMeaning
=color or value=colorYesFace color in RGB or RGBA hexadecimal form.

<color=#00FF0080>Half-alpha green</color>

#00FF0080Half-alpha green

gradient

A gradient accepts exactly one complete attribute set. Mixing sets or omitting a member is invalid.

fitNoComplete tagged textglyph samples each shaped text position; span applies one shared sample to the complete span. Omitting the attribute distributes the gradient across the complete tagged text; fit=text is not a valid explicit value.
hzNo0Finite number of complete flowing cycles per second. Must be zero or greater; zero keeps the gradient static.
directionNoforwardforward or reverse. Controls the flow direction when hz is non-zero.

When fit is omitted, the gradient is distributed across the complete tagged text, preserving the original behavior. For a horizontal gradient, explicit fit=span samples the color at the first span position and applies that single color to every vertex of every glyph in the span; at time zero this is the left color. For a horizontal gradient, fit=glyph samples one color per shaped text position and applies it uniformly to that glyph; time advances those samples through the color range. Vertical and four-corner gradients with fit=glyph retain their per-glyph vertex gradients. Optional hz specifies complete flowing animation cycles per second; its default of zero keeps the gradient static. The repeating mirrored color ramp flows continuously and wraps without a color jump. direction=forward is the default; use direction=reverse to reverse the flow.

<gradient hz=0.25 direction=reverse fit=span left=#FF0000 right=#0000FF>One animated span color</gradient>

The text layout outputs underline and strikethrough geometry rather than inserting decoration glyphs into the shaped text. Position effects such as shake and wave move the text while its decorations remain stable.

shadow

Adds a hard shadow to the enclosed text. At least one attribute is required. Attributes omitted by a nested tag retain the enclosing shadow value; attributes omitted by the outermost tag retain the label font's shadow value.

AttributeRequiredMeaning
colorNoShadow color in #RRGGBB or #RRGGBBAA form.
xNoHorizontal shadow offset in layout units. Positive values move it right.
yNoVertical shadow offset in layout units. Positive values move it up.
blurNoFinite, non-negative blur radius in layout units.
 
<shadow x=3 y=-3 blur=2 color=#000000A0>Shadow</shadow>
<shadow x=-2>Override only the horizontal offset</shadow>
x=3, y=-3, blur=2Hard shadow
Shadow blur is generated into the glyph atlas. A span can request a smaller blur than the font's baked blur; larger values are preserved in the layout but currently render using the largest blur available in the atlas.

shake

Applies a deterministic animated random offset without changing line breaking or layout bounds. The effect keeps time internally; scripts do not need to modify the label text for each animation frame.

amplitude0.5Finite value ≥ 0Maximum displacement in layout units.

wave

Moves characters up and down in an animated sine wave without changing line breaking or layout bounds. The layout accumulates animation time when it is updated.

sprite

Adds a self-closing sprite object at the current position in the visible text. Its attributes are preserved as metadata for label.get_layout_objects().

AttributeRequiredMeaning
idNoStable identifier hashed into the returned layout object's id. An identifier is generated when this is omitted.
srcNoApplication-defined direct resource identifier, conventionally a project path.
atlasNoApplication-defined atlas identifier.
animationNoApplication-defined animation identifier within an atlas.
widthNoResolved sprite width. Defaults to 1em.
heightNoResolved sprite height. Defaults to 1em.
Any other attributeNoApplication-defined metadata preserved for the object resolver and label.get_layout_objects().
 
<sprite src=images/icon.png/>
<sprite src=images/banner.png width=4em height=2em/>
<sprite atlas=images/icons.atlas animation=coin width=2em/>
Inline image equivalentCollect 100 coins

Dimensions accept positive bare layout units, px, em, or %. Both em and % use the label's base font size.

Each missing dimension defaults independently to 1em. Omitting both produces a 1em × 1em object; specifying only the width does not derive the height from a resource aspect ratio.

Sprites reserve their resolved dimensions in the label layout, but labels do not render the resource automatically. The src, atlas, and animation attributes are not resolved automatically.

a

Describes a range of visible text as a link object. The enclosed text is laid out normally and receives the named link style by default. Interaction state overlays pseudo-state styles such as link:hover and link:active without reshaping the text.

AttributeRequiredMeaning
hrefNoConventional link destination. The value is returned as a string without automatic validation or navigation.
idNoStable identifier hashed into the returned layout object's id. An identifier is generated when this is omitted.
styleNoNamed base style. For example, style=menu_link uses menu_link, menu_link:hover, and menu_link:active.
Any other attributeNoApplication-defined metadata, such as an identifier, action, tooltip, or analytics value.
 
<a id=website href=https://defold.com>Defold</a>
<a id=inventory style=menu_link action=open_inventory item=sword>Iron sword</a>
link / :hover / :activeDefold

The text layout owns each object's interaction state, while its caller supplies pointer enter, leave, press, and release transitions. The fontviewer demonstrates hover, active, cursor, and click behavior. Label-component input messages are not wired yet.

Named styles

Each font collection contains render-only named styles. Defold provides default link, link:hover, and link:active colors. Define a style with a text string containing opening tags. The tags are implicitly closed in reverse order, so closing tags and visible text are not allowed.

font.set_style("/fonts/ui.fontc", "link",
    "<color=#2673ff><outline color=#000000 size=1>")

font.set_style("/fonts/ui.fontc", "link:hover",
    "<color=#66b3ff><shake amplitude=0.2 hz=20>")

Tags are applied from left to right, as though they were nested around the link text. State styles are then applied in the order :visited, :hover, :active, and :disabled. Static fields supplied later replace earlier fields; effects are appended in order.

Calling font.set_style() replaces that complete named definition. Named styles accept render-only tags such as color, outline, shadow, gradient, wave, and shake. Layout-changing and object tags are rejected.

Layout object API

Use label.get_layout_objects() to retrieve the sprite and link objects from a label after assigning its text.

label.get_layout_objects()

objects = label.get_layout_objects(url)
ArgumentTypeDescription
urlstring, hash, or urlThe label component to inspect, for example "#label".

The function returns a newly created array containing the current layout objects in source order. It returns an empty array when the label contains no object tags. Since the objects and their attributes are copied into Lua on every call, cache the result and query again after changing the text or another property that changes its layout.

Returned object fields

FieldTypeDescription
typestring"sprite" or "link".
idhashObject identifier used for state updates and interaction messages.
statenumberCurrent layout-owned interaction-state bit mask.
text_offsetnumberZero-based position in the visible text, counted in Unicode codepoints after markup has been removed and entities have been decoded. For a sprite, this is its insertion point.
text_lengthnumberLength of the enclosed visible text in Unicode codepoints. A sprite has length one for its inserted U+FFFC object-replacement codepoint.
widthnumberResolved width in label layout units. Links currently have width zero.
heightnumberResolved height in label layout units. Links currently have height zero.
attributestableAll tag attributes as string key/value pairs. Attribute values retain their source representation, such as "2em". A shorthand unnamed value is stored under the key value.
text_offset and text_length are not UTF-8 byte offsets. A non-ASCII character such as å or 猫 counts as one position.

Lua example

local text = [[
Read the <a href=https://defold.com/manuals/ id=manual>manual</a>
or inspect <sprite src=images/info.png width=2em/> for more information.
]]

label.set_text("#label", text)

local objects = label.get_layout_objects("#label")
for _, object in ipairs(objects) do
    if object.type == "link" then
        print("link", object.attributes.href)
        print("visible range", object.text_offset, object.text_length)
    elseif object.type == "sprite" then
        print("sprite", object.width, object.height)
        pprint(object.attributes)
    end
end

Useful combinations

Colored outline with a horizontal gradient

<outline size=2 color=#101820>
    <gradient left=#FEE715 right=#FF6F61>Gradient title</gradient>
</outline>

The gradient multiplies the face color only; the outline keeps its own color.

Shake a sentence, gradient one word

<shake hz=20 amplitude=0.5>
    This <gradient left=#FF00FF right=#FFFFFF>whole</gradient> text shakes!
</shake>

The outer position effect applies to every glyph. The nested color effect applies only to “whole”.

Override one property without losing the others

<color=#FFFFFF><outline size=2 color=#000000>
    Normal <color=#FF4040>warning</color> normal
</outline></color>

The inner color changes the face while retaining the inherited outline width and color.

Error handling and recovery

Labels parse markup in recovery mode. When possible, malformed markup is displayed as literal text and parsing resumes at a later valid tag. This makes the error visible without preventing the rest of the label from being styled.

<col or=#000000>hello</color> <size=+4>world</size>

Here the broken first section remains visible for diagnosis, while the later valid size span can still work. Invalid UTF-8 and representation-limit errors remain fatal.

Syntactically valid styling tags may still contain an invalid value, such as an unknown fit value, an unsupported color, or an incomplete gradient attribute set. The failed tag and its nested styling are ignored and logged. Its text keeps the nearest valid ancestor style, and styling resumes at the next sibling tag on the same hierarchy level. Invalid layout-object values, such as a non-positive sprite dimension, remain fatal and make the label fall back to displaying its source as plain text.
