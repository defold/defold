# Modelc compression fixtures

Tests consume committed files; no encoder or Python installation is needed to run
`test_model`. Compression is decoded automatically. Invalid compressed data must
fail the import, even if fallback geometry exists.

## Provenance

`box/glTF` and `box/glTF-Draco` are unchanged copies of the Box model from
[Khronos glTF Sample Models](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Box),
provided locally in `example-gltf-reference/2.0/Box`. Cesium donated this model for
glTF testing under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The Meshopt Box variants are derived from its uncompressed buffers, without
vertex optimization, reordering, or quantization. Draco's upstream Box stream is
retained rather than re-encoded.

The small `meshopt` streams and `draco` quads are generated by the accompanying
Defold fixture generators. The Draco quads deliberately assign unique attribute
IDs 42, 77, 101, and 205, independent of glTF accessor indices. Colors and weights
share one stored Draco value across multiple points. `shared.gltf` uses the same
attribute accessors in two primitives whose decoded positions differ by ten
units; one uses a triangle list and the other a strip.

## Regeneration

Run these commands from the repository root. These examples use macOS; Linux can
replace `-dynamiclib`/`.dylib` with `-shared -fPIC`/`.so` for Meshoptimizer.

```sh
c++ -O2 -std=c++98 -dynamiclib \
  external/meshoptimizer/package/meshoptimizer-1.2/src/allocator.cpp \
  external/meshoptimizer/package/meshoptimizer-1.2/src/vertexcodec.cpp \
  external/meshoptimizer/package/meshoptimizer-1.2/src/vertexfilter.cpp \
  external/meshoptimizer/package/meshoptimizer-1.2/src/indexcodec.cpp \
  -o /tmp/modelc-meshopt-fixtures.dylib
python3 engine/modelc/src/test/assets/compression/generate_meshopt.py \
  /tmp/modelc-meshopt-fixtures.dylib
```

Draco fixture generation needs the full pinned upstream release because
`build_ext` intentionally builds only the decoder. Download and verify the
archive using the checksum in `external/draco/README.md`, then extract it in
`/tmp/draco-1.5.7`:

```sh
cmake -S /tmp/draco-1.5.7 -B /tmp/modelc-draco-fixtures \
  -DCMAKE_BUILD_TYPE=Release -DDRACO_GLTF_BITSTREAM=ON -DDRACO_TESTS=OFF
cmake --build /tmp/modelc-draco-fixtures --target draco -j8
c++ -O2 -std=c++11 -I/tmp/draco-1.5.7/src -I/tmp/modelc-draco-fixtures \
  external/draco/generate_test_mesh.cpp /tmp/modelc-draco-fixtures/libdraco.a \
  -o /tmp/modelc-generate-draco
python3 engine/modelc/src/test/assets/compression/generate_draco.py \
  /tmp/modelc-generate-draco
```

Neither generator changes the supplied Box originals. Regenerating with these
versions should leave all fixture bytes unchanged.

## Coverage

- Box: geometry and winding, normals, all bounds, materials, and node transforms.
  Triangle matching permits cyclic rotation and reordering, but rejects reversed
  winding. Draco tolerance is 0.001 for positions/bounds and 0.01 for normals;
  Meshopt Box comparisons are exact.
- EXT and KHR attribute bitstreams; TRIANGLES and INDICES modes at 16/32 bits;
  OCTAHEDRAL at 8/16 bits, QUATERNION, EXPONENTIAL, and KHR COLOR at 8/16 bits.
  Golden filtered outputs capture the codec's documented quantization.
- `streams.gltf`: interleaved position/UV data, compressed skinning, sparse morph
  indices and values, normalized quaternion animation, exponential translation
  animation, and color filtering. Tests assert the triangle's known arrays
  directly, with a 1/255 RGB tolerance for COLOR filtering.
- Draco unique-ID lookup, shared accessors, mapped/normalized attributes, triangle
  lists and strips, and ordinary attributes/morph data outside Draco.
- External buffers, embedded data URIs, GLB, omitted and unused fallback buffers,
  material/mesh-metadata loads, corrupt/truncated streams, layout/range/size
  errors, attribute mismatches, and invalid decoded geometry/sparse indices.

Build the native CMake `test_model` target and run its executable with
`engine/modelc` as the working directory. The fixture tests live in
`test_model_compression.cpp`. For ASan/UBSan checks, build both codec archives and
the native tests with sanitizers; the normal JNI library uses the existing
sanitizer-exclusion settings and unsanitized dependencies.

See [VALIDATION.md](VALIDATION.md) for measured results and platform coverage.

There are 13 test-data files:

- Four unchanged files for the original and Draco Box.
- Four Meshopt Box files: external EXT glTF/bin, embedded EXT glTF, and KHR GLB.
- One generated `meshopt/cases.h` table for all eleven small mode/filter vectors,
  following dlib's embedded test-data pattern.
- Three Meshopt triangle scenes: valid, invalid indices, and invalid sparse indices.
- One Draco scene with shared attributes and both supported topologies.

Bob's `createTestJar` packages the same `box/glTF-Meshopt/Box-embedded.gltf` and
`draco/shared.gltf` as `box_meshopt.gltf` and `draco_shared.gltf` under
`com/dynamo/bob/pipeline`. There are no second copies in the Bob source tree.
The EXT v0 bitstream also exercises the KHR extension in Bob tests. The Draco
test checks shared accessor isolation, both topologies, and normalized colors
through `ModelUtil.loadScene` and JNI.
